# Ziewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Rust binary that serves configured folders of Markdown/HTML with GitHub-style + Mermaid rendering, gated by IP allow-list with an admin approval flow, installable as an OS service.

**Architecture:** axum server with an access middleware that classifies each request's client IP as Admin/Allowed/Denied. Pure modules (`config`, `access`, `fs_tree`, `render`, `requests`) hold all logic and are unit-tested; `web/*` wires them to routes and minijinja templates; assets are embedded with rust-embed.

**Tech Stack:** Rust stable (2021 edition), axum 0.8, tokio 1, tower-http 0.6, clap 4 (derive), serde/serde_json/toml 0.8, dotenvy 0.15, comrak (with `syntect` feature), minijinja 2, rust-embed 8, ipnet 2, mime_guess 2, service-manager 0.7, tracing + tracing-subscriber. Dev: tempfile, tower (util), http-body-util.

**Spec:** `docs/superpowers/specs/2026-11-10-ziewer-design.md`

## Global Constraints

- Binary/crate name `ziewer`; service label `ziewer`.
- Config file `ziewer.toml`; path precedence: `--config` > `ZIEWER_CONFIG` > `./ziewer.toml`. `.env` in CWD loaded first (dotenvy, ignore if missing).
- Env overrides: `ZIEWER_LISTEN`, `ZIEWER_ADMIN_IP`, `ZIEWER_TRUST_PROXY`, `ZIEWER_ALLOWED_IPS` (comma-separated), `ZIEWER_FOLDERS` (`Name=/path,Name2=/path2`). Env-set fields are never written back and are read-only in admin.
- Pending requests file: `requests.json` in the config file's directory.
- No CDN: `mermaid.min.js` (mermaid@11.4.1) and `github-markdown.css` (github-markdown-css@5.8.1, the auto light/dark file) vendored into `assets/vendor/` and embedded.
- Only `.md` and `.html` (case-insensitive extension) appear in trees. Names starting with `.` are hidden everywhere (tree + 404).
- Request note max 200 chars; max 100 pending requests; per-IP re-submit at most once per 600 s → 429.
- Security headers on every response: `X-Content-Type-Options: nosniff`, `Referrer-Policy: same-origin`, `X-Frame-Options: SAMEORIGIN`.
- All mutations are POST; reject (403) when `Origin` is present and its host[:port] ≠ `Host` header.
- `cargo clippy --all-targets -- -D warnings` and `cargo test` pass at the end of every task.

## Review Focus

1. **Directory URL without trailing slash** (`/f/docs/guide`) — relative links/images in its README would resolve against the parent; expect a 308 redirect to `/f/docs/guide/`. Test in Task 6.
2. **File names with spaces / non-ASCII** (`My Notes/é.md`) — tree links must be percent-encoded and the route must decode them and serve the file. Test in Task 6.
3. **Symlink loop or symlinked dir inside a root** — tree building must not hang or recurse forever; symlinked directories are skipped in the tree. Test in Task 3.
4. **HTML in an access-request note or user agent** (`<script>alert(1)</script>`) — a denied stranger's input must be escaped on the admin page, not executed. Test in Task 8.
5. **Admin adds a duplicate IP, an invalid IP, or a folder whose slug collides** — duplicate IP is a no-op (no second entry), invalid input and slug collision show an error on the admin page and leave the config file unchanged. Test in Task 8.

Routes and behavior (spec §4):
- `GET /` → 302 to `/f/{first-slug}/`, or error page "No folders configured".
- `GET /f/{slug}` and `GET /f/{slug}/{*path}`:
  - unknown slug / `resolve` None → 404 error page.
  - directory whose URL lacks trailing `/` → 308 to URL + `/`.
  - directory → `view.html` with `tree = build_tree(root)`, and either `dir_index` rendered (md → `markdown_to_html`, html → iframe) or `list_dir` listing.
  - `.md` → `view.html` with rendered article; `?raw=1` → `text/plain; charset=utf-8`.
  - `.html` → `view.html` with `<iframe class="html-frame" src="{same path}?raw=1">`; `?raw=1` → `text/html` body passed through `inject_mermaid`.
  - other files → raw bytes, `mime_guess` content type.
- `GET /_assets/{*file}` → embedded `assets/` with mime type; 404 if missing.
- Template context for `base.html`: `folders` (name, slug, active), `is_admin`, `tree`, `current_path`, `title`. Tree links are `/f/{slug}/{rel_path percent-encoded per segment}`; route path is percent-decoded before `resolve`.
- `base.html` loads `/_assets/vendor/github-markdown.css`, `/_assets/app.css`, `/_assets/vendor/mermaid.min.js`, `/_assets/app.js`. `app.js`: `mermaid.initialize({startOnLoad: true, theme: matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'default'})`; resize `.html-frame` iframes to `contentDocument.documentElement.scrollHeight` on load.
- `main.rs`: clap `Cli { #[arg(long, env = "ZIEWER_CONFIG", default_value = "ziewer.toml", global = true)] config: PathBuf, #[command(subcommand)] cmd: Cmd }`, `Cmd::Serve` (other variants in Task 9).
